pyLogDigitizer

pyLogDigitizer turns scanned paper well logs (TIFF) into LAS files, with a local browser app to check and fix every step. Nothing leaves your machine.

Overview

pyLogDigitizer turns scanned paper well logs (TIFF) into LAS files. Lots of older wells only exist as paper scans, and digitizing them by hand is slow and hard to check. So I built a tool that does the tedious parts (finding tracks and grids, reading depth labels, tracing curves) and gives you a local browser app to check and fix every step. Curves that run off the track and come back on a backup scale get unwrapped automatically. Everything runs on your own machine and nothing is uploaded.

Examples

Example scans and LAS files are from the Kansas Geological Survey.

Key features

01

Layout and scales

Automatic track, grid and depth-label detection, plus scale calibration.

02

Curve tracing

Fast curve tracing with click-to-fix anchors and backup-scale unwrapping.

03

Optional ML

Optional U-Net cost map that learns from your corrections.

04

Check and export

QC against a reference LAS and LAS 2.0 export.

Installation

pip install pylogdigitizer

The browser app, the faster tracer, and the ML model are optional add-ons; the README lists them.
