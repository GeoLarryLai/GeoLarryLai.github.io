Overview

pyBasinSubs is a Python tool for 1-D and 2-D backstripping and decompaction basin analysis. Start with a well, stratigraphic column or interpreted section to explore subsidence, burial, thermal history and structural restoration. The method paper is Lai et al. (2022), Extremely rapid up-and-down motions of island arc crust during arc-continent collision, Communications Earth & Environment 3, 100.

Version 0.2.0 combines 1-D Airy backstripping and decompaction with optional thermal views: a time-evolving column and geotherm, burial temperature, and kinetic Easy%Ro oil, wet-gas and dry-gas windows. The 2-D workflow provides flexural backstripping and decompaction, restoration comparisons, and an explicit fixed-trace growth-reconstruction prototype.

The local browser app uses step-by-step workflows for inputs, compaction, calculation and export. Start it with pybasinsubs-app or its alias pybasinsubs-ui; pybasinsubs-tracer opens the fault editor directly. It runs locally, and input files stay on the user's computer. Python notebooks provide worked examples using the same calculation engines.

Interpretation limits

Under active development: many functions, especially fault restoration, are experimental and not fully validated. Use geological constraints; a restored section is not a unique solution.

The fixed-trace growth prototype infers nonnegative, distributed apparent throw, not resolved down-dip slip, geological heave or curved-fault balancing. Zero is an assumed datum. The westernmost fault's footwall is flattened separately toward the datum and is not counted as throw. Traces remain user-controlled inputs; default VG1 traces were not replaced, and the optional tip-extension assist was not applied. The oldest interval retains the last constrained 170.3-Ma geometry, not an inferred 252-Ma section. Growth reconstruction is an explicit step, not part of ordinary Run section.

Key features

01

1-D basin history

Airy backstripping and decompaction with erosion, over-compaction and Monte Carlo uncertainty, using bundled examples or a column CSV.

02

Thermal history and maturity

Column/geotherm and burial-temperature views with kinetic Easy%Ro maturity windows.

03

2-D restoration and growth

Flexural backstripping and decompaction, interpreted fault traces, and fixed-trace growth reconstruction with aligned apparent-throw and decompacted sedimentation rates.

04

Whole-section thermal timesteps

Isotherms and oil, wet-gas and dry-gas window overlays, with percent-in-window lines for remaining units through time. These are independent steady columns, not 2-D heat conduction.

Installation

pip install pybasinsubs

Python 3.10 or newer. Start the local browser app with pybasinsubs-app or pybasinsubs-ui; pybasinsubs-tracer opens the fault editor directly.
