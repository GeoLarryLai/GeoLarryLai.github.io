A Python toolkit for pairwise stratigraphic correlation analysis among sediment cores and well-log data.

Lai, L.S.-H., Sylvester, Z., Covault, J.A., Gomberg, J.S., Nieminski, N.M. (Accepted 2026) Reproducible event-bed correlation with uncertainty: pyCoreRelator. Sedimentology.

Python · Rust

SubsurfiX →

SubsurfiX from a folder of well logs to a 3D property model you can simulate on. Log QC, gap filling, well correlation, property modeling, and flow and heat simulation in one Rust engine, run from Python or the command line, with every filled value traceable.

Lai, L.S.-H. (2026) SubsurfiX. Zenodo, https://doi.org/10.5281/zenodo.23832007

Python · R

pyBasinSubs →

pyBasinSubs reconstructs how a sedimentary basin sank and filled through time by backstripping its layers. It's a new Python package that extends my original R code, BasinSubs (Lai et al., 2021, *Sedimentary Geology*; Lai et al., 2022, *Communications Earth & Environment*), which stays available as its own repo.

Lai, L.S.-H. (2026) pyBasinSubs. Zenodo, https://doi.org/10.5281/zenodo.23832018

pyLogDigitizer →
