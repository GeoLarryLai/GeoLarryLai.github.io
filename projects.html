GitHub Projects

I build reproducible pipelines and custom algorithms for subsurface logs and land-surface topography when existing tools fall short.

pyCoreRelator

A Python toolkit for pairwise stratigraphic correlation analysis among sediment cores and well-log data.

pyTopoComplexity

A Python package for multiscale topographic complexity analysis.

pyValleyWidth

Codes for pytopotoolbox to extract valley width.

pyPetrograph

ML-applied toolkits for rock thin-section petrographic analysis.

pyLogCrafter

Basin-scale well-log quality control, spatial normalization, gap filling, and electrofacies tools. Under development.

pyRockImageLab

Rock-photograph workflows for core-box crop, stitch, and mosaic. Under development.

pyBasinSubs

R scripts for basin subsidence analyses of Taiwan Coastal Range. A newer package is not published yet.
